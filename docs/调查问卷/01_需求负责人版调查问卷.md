# 前端体验走查工具调查问卷（需求负责人版）

## 问卷说明

本问卷用于确认“为什么做、先做什么、做到什么程度算成功”，不要求回答技术实现细节。预计填写 15～20 分钟，也可作为访谈提纲。

目前设想的初步方式是：研发在浏览器中主动走查，数据只在部门内机器分析，生成质量报告，作为提测准入依据；一期暂不在公司研发协同系统中自动拦截。请重点判断这种方向是否符合实际需要。
